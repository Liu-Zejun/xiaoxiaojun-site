# 小小俊的个人网站（新手样板）

这是一个非常简单的个人网站样板，只有 3 个文件需要你理解：

```text
小小俊个人网站制作/
├─ index.html     入场页（赛博朋克动态城市视频，点击进入网站）
├─ home.html      网站正文（文字、图片、按钮都在这里）
├─ css/style.css  网页的样子（颜色、大小、间距）
├─ js/main.js     网页的行为（菜单开关、回到顶部等小功能）
├─ images/avatar.jpg  首页头像图片
├─ videos/entry-cyberpunk.mp4  入场页 1080P 动态背景视频
└─ README.md      这份说明
```

## 怎么看效果

双击 `index.html` 会先看到赛博朋克城市夜景的动态视频，点击任意位置进入 `home.html` 正文页面。

想边改边看，推荐安装 VS Code（免费），再装一个叫 Live Server 的插件，右键 `index.html` 选择 "Open with Live Server"，之后每次保存都能自动刷新。

## 新手第一步：改文字

1. 用 VS Code 打开 `index.html`。
2. 搜索你想改的字，比如 `小小俊`、`关于我`、`481116384@qq.com`。
3. 改成你自己的名字、介绍和邮箱，保存后刷新浏览器。

想换头像：头像图片放在 `images/avatar.jpg`。想换成别的照片，就把新照片改成这个名字放进去，或者直接替换这个文件。

## 新手第二步：改颜色

打开 `css/style.css`，文件最上面有一块叫 `:root` 的区域，那里就是配色表：

```css
--gold: #c6a468;       /* 金色点缀 */
--sea-deep: #35535e;   /* 深海蓝 */
--copper: #c08a6b;     /* 日落铜色 */
```

随便换个颜色值，比如 `#c6a468` 改成 `#d0b070`，刷新就能看到变化。

页面里还内置了几个小模块：阅读进度条、顶部实时日期时间、一键复制邮箱、数字滚动计数、滚动浮现、返回顶部和移动端菜单，全部不需要安装插件。

## 相册地图怎么放自己的照片

相册地图页是 `travel.html`，点首页“作品 → 我的相册”可以打开。

你的照片会置顶显示，方法：
1. 在 `travel` 文件夹里建一个省份文件夹，比如 `travel/北京/风景/` 或 `travel/北京/美食/`。
2. 把照片放进对应栏目文件夹，文件名改成 `1.jpg`、`2.jpg` 这样。
3. 打开 `js/travel-data.js`，找到对应的省份，按栏目写照片路径，例如：

```js
"北京": {
  "风景": ["travel/北京/风景/1.jpg", "travel/北京/风景/2.jpg"],
  "美食": ["travel/北京/美食/1.jpg"]
}
```

4. 保存后刷新页面，点地图上的“北京”，再切到“风景”或“美食”栏目，照片就会显示出来。

照片建议先用工具压缩成宽度 1200 左右再放进去，网页打开会更快。

其他朋友访问时可以点“上传照片”把照片放进当前省份的当前栏目，也能给每张照片点赞或取消点赞，照片会按点赞数排序。目前上传和点赞保存在各自的浏览器里，等以后接上服务器就能互通。

上传照片后，本机（网站主人）可以点任意照片下方的“选择地点”选到具体的市和区县，也可以右键删除上传的照片。访问者只能给自己上传的照片选择地点，不能修改或删除别人上传的照片。

## 新手第三步：放第一个作品

在 `index.html` 里找到 `<div class="works-grid">`，把其中一段 `<article class="work-card">...</article>` 复制一份，改成你的作品名和介绍。

## 之后的路

1. 先把这个样板改得完全像你自己。
2. 学会在手机上打开自己的网页：把文件发给手机，或用 VS Code 的 Live Server 配合手机同一 Wi-Fi 预览。
3. 想让人家通过网址访问，就用免费托管：GitHub Pages、Netlify 或 Vercel。
4. 慢慢学三样基础：HTML（内容）、CSS（样式）、JavaScript（交互）。

这个文件夹已经是一个 Git 仓库，可以用 `git` 保存每次修改，出问题还能退回上一版。学完第一步改内容之后，就可以开始用了。
